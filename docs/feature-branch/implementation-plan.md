## Задача 1. Кастомный тултип проекта: заказчик и руководитель проекта (бэклог #7)

### Цель

Создать **переиспользуемый компонент кастомного тултипа** (тёмно-серый фон, белый текст) в UI-ките и применить его на «Ресурсном плане»: при наведении на название проекта показывать тултип с содержанием:

```
Проект: <название проекта>
Тип: <тип проекта>
Заказчик: <заказчик>
РП: <руководитель проекта>
```

### Текущее состояние

- Текст подсказки строится функцией `projectHoverTitle()` в `src/pages/ResourcePlan/ResourcePlan.vue:120-129`: формат `Имя (тип, заказчик) — описание`. Руководитель проекта (`Project.projectManager`) в текст не попадает.
- Подсказка выводится через нативный атрибут `title` на `.plan__project-name` в `PlanTableRow.vue`; кастомного тултип-компонента в UI-ките нет (`src/components/ui/` — только BaseButton, BaseInput, ConfirmDialog).

### Объём и оценка

- Оценка бэклога (1 ч) относилась к нативному `title`; с переиспользуемым компонентом реальный объём **~5 ч** (компонент + тесты + интеграция).
- Незаполненные поля проекта (тип/заказчик/РП) в тултипе пропускаются; описание проекта в новом формате не показывается (его нет в согласованном содержании).
- Компонент должен быть универсальным — далее пригодится для шапки групп, DataManage и кнопки «Актуализировано» (бэклог #13).

## Задача 2. Шапка групп: свитч «доступно / запланировано» (бэклог #5)

### Цель

Подпись под каждой колонкой группы должна показывать реально свободные часы (мощность − распределено), а не общую мощность. Свитч на 2 состояния переключает подпись: «доступно: … ч» (сколько часов осталось) ⇄ «запланировано: … ч» (сколько всего запланировано). Перегруз (распределено больше мощности) подсвечивается. Нативный тултип (`title`) шапки колонок убирается совсем.

### Текущее состояние

- Подпись `доступно: X ч` в `PlanTableHeader.vue:58-61` (обычные режимы) и `:99-102` (режим 4 кварталов) показывает `effectiveCapacityByColumn(col) * chartCapacityMultiplier` — это **общая ёмкость**, не остаток.
- Распределённые часы по колонке уже считает `columnTotal(col)` в `useColumnTotals.ts:48-53` (учитывает режим просмотра: год или выбранный квартал); множитель ёмкости — `chartCapacityMultiplier` (`useColumnTotals.ts:153-155`).
- Подсветка перегруза шапки уже есть (`plan__th--over` через `isColumnOverCapacity`), но сама подпись не подсвечивается.
- Образец свитча на 2 состояния уже есть в `PlanToolbar.vue:33-50` («По группе ресурса / По типу ресурса») — переиспользовать разметку и стили `plan__switch`.
- Состояние режимов страницы живёт в `useViewMode.ts` (не персистится — новый свитч делаем так же).
- Нативный тултип шапки строит `columnHeaderTitle()` в `ResourcePlan.vue:83-96`; выводится через `title` в `PlanTableHeader.vue` (строки 45, 49, 86, 90). По новому решению тултип удаляется совсем — вместе с ним уходит и показ описаний групп при наведении.
